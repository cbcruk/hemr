# 급여 본인부담 (한의원 외래)

건강보험·의료급여 환자가 한의원 외래에서 내는 급여 본인일부부담금입니다. 현행 클라이언트는 이 금액을 서버에서 받아 그렸기 때문에 포팅할 클라이언트 규칙이 없습니다. 그래서 이 문서는 다른 규칙 문서와 달리 법령 원문에서 정리했고 픽스처가 없습니다. 2026-11-07에 현행인 판을 기준으로 했습니다.

신뢰도 표기는 다음과 같습니다.

- **[P]:** law.go.kr의 현행 법령이나 보건복지부 원문에서 직접 읽은 내용
- **[S]:** OK차트 매뉴얼·언론 기사 같은 2차 자료
- **[U]:** 확인하지 못한 내용

## 요약

- 건강보험 기본은 요양급여비용 총액의 **30%**입니다. 총액은 10원 미만을 버리고, 본인부담은 **100원 미만을 버립니다**(외래) [P]
- 1세 미만 **5%**, 임신부 **10%**, 1세 이상 6세 미만 **21%**(30%의 70%) [P]
- 65세 이상은 총액 구간에 따라 **1,500원 / 10% / 20% / 30%**입니다. 한약제제를 투약하면 10%·20% 구간이 5,000원씩 넓어집니다. 경계값은 아래 구간에 들어갑니다 [P]
- 의료급여 1종·2종은 1회 방문당 **1,000원**, 직접조제(투약)면 **1,500원**의 정액입니다. 총액이 더 적으면 총액만 냅니다. 1세 미만과 1종 면제 대상은 0원입니다 [P]
- 비급여와 100/100 항목은 총액에 넣지 않고 따로 전액 받습니다 [P]
- 추나는 그 금액만 따로 50%(따로 고시분 80%), 첩약 시범사업분은 30%로 매기고, 나이·특례 경감을 적용하지 않습니다 [P]. 서버는 아직 계산하지 않습니다(아래 [서버 구현](#서버-구현))

## 로직

### 건강보험 [P]

별표 2 제1호 본문은 "요양급여비용 중 … 금액(100원 미만은 제외한다)을 부담한다. 다만, 입원진료의 경우에는 100원 미만의 금액도 부담한다"입니다. 같은 호 나목의 한의원 행은 다음과 같습니다.

> 요양급여비용 총액 × 30/100(임신부 외래진료의 경우에는 10/100, 1세 미만 영유아 외래진료의 경우에는 5/100). 다만, 요양급여를 받는 사람이 65세 이상이면서 해당 요양급여비용 총액이 보건복지부령으로 정하는 금액을 넘지 않으면 보건복지부령으로 정하는 금액을 본인일부부담금으로 한다.

```
total = floor10(급여 라인 합)
copay = floor100(total × rate)
```

- 총액의 10원 미만 절사는 명세서 작성요령의 규칙입니다. 첩약 지침이 "요양급여비용총액 … 10원 미만은 절사", "본인일부부담금 … 100원 미만 절사"라고 씁니다 [P]. 일반 명세서 작성요령 원문은 열어 보지 못했고, OK차트도 같은 순서입니다 [S]
- 버린 100원 미만은 공단 청구액으로 갑니다(청구액 = 총액 − 본인부담) [S]
- 1세 이상 6세 미만은 별표 2 제3호다목1) "본인이 부담할 비용의 부담률의 100분의 70"이라 30% × 0.7 = 21%입니다
- 나이는 진료일 기준 만 나이입니다. 생일 당일부터 한 살 많습니다(행정기본법 제7조의2) [S]

### 65세 이상 [P]

시행규칙 [별표 3] 제1호, "의원·치과의원(의약분업 예외지역만 해당)·보건의료원(한방과만 해당)·한의원" 행입니다.

| 구분 | 요양급여비용 총액 | 본인부담 |
|---|---|---|
| 투약 처방을 하는 경우 | 15,000원 이하 | 1,500원 |
| | 15,000원 초과 ~ 25,000원 이하 | 10% |
| | 25,000원 초과 ~ 30,000원 이하 | 20% |
| | 30,000원 초과 | 30% (별표 3 범위 밖, 별표 2) |
| 투약 처방을 하지 않는 경우 | 15,000원 이하 | 1,500원 |
| | 15,000원 초과 ~ 20,000원 이하 | 10% |
| | 20,000원 초과 ~ 25,000원 이하 | 20% |
| | 25,000원 초과 | 30% |

- 원문이 "넘지 않는 경우"라 경계값은 아래 구간입니다. 15,000원이면 1,500원입니다
- "투약 처방"은 보험 한약제제 투약으로 봅니다 [S]. 첩약 시범분은 따로 명세서를 써서 투약으로 보지 않습니다. 지침 Q&A가 비 시범사업 내역(S028)의 65세 이상에 "투약처방 하지 않는 경우"를 적용한다고 씁니다 [P]
- 1,500원 정액은 절사할 일이 없고, 10%·20%는 100원 미만을 버립니다

### 의료급여 [P]

의료급여법 시행령 [별표 1] 제1차 의료급여기관(의원·한의원) 외래입니다.

| | 한의사가 한약·한약제제를 직접 조제 | 그 밖의 외래 |
|---|---|---|
| 1종 | 1회 방문당 1,500원 | 1,000원 |
| 2종 | 1,500원 | 1,000원 |

- 1종·2종 나목: "급여비용총액이 해당 규정의 본인부담금보다 적은 경우에는 그 급여비용총액 전부를 본인부담금으로 한다". 따라서 `copay = min(정액, total)`입니다
- 직접조제하면서 처방전도 발행하면 1,000원입니다(비고)
- 1세 미만 외래는 기금이 전부 냅니다(제2호머목)
- 1종 면제(제1호다목): 18세 미만, 임산부, 무연고자, 노숙인, 고시 결핵·희귀난치·중증질환자 등입니다. 자격 조회의 본인부담여부 `M003`–`M018`로 옵니다 [S]
- 1종 선택의료급여기관(`M001`·`M002`): 우리 기관이 1·2차 선택기관이면 0원, 3·4차면 정액입니다. 선택기관이 아닌 기관은 의뢰서(`B005`)를 가져오면 정액이고, 아니면 전액 본인부담입니다 [S]
- 1종 본인부담은 건강생활유지비(월 6,000원)에서 먼저 뺍니다. 그만큼은 환자에게서 받지 않습니다 [S]
- 연장승인 미신청자(`B014`)는 총액의 30%입니다 [S]
- 2024~2025년의 정률제 개편안(1종 의원 4% 등)은 보류됐고, 현행 별표 1은 여전히 정액입니다 [P]

### 추나 [P]

별표 2 제3호거목: "가목1)·2)·3), 나목, 다목1), 마목, 자목 및 하목에도 불구하고 … 추나요법에 대하여 … 해당 요양급여비용의 100분의 50. 다만, … 따로 정하여 고시하는 추나요법 … 100분의 80".

- 추나 금액에만 50%(따로 고시분 80%)를 매기고 나머지는 원래 부담률로 따로 계산해 더합니다
- 6세 미만 경감, 산정특례, 조산아 경감을 추나분에는 적용하지 않습니다
- 80% 대상은 디스크·협착증 외 근골격계 질환의 복잡추나입니다 [S]. 고시 원문은 열지 못했습니다 [U]
- 의료급여 추나는 1종 30%, 2종 40%, 따로 고시분 80%입니다(의료급여법 시행령 별표 1 제3호라목) [P]
- 65세 이상: 구간 판정 총액에 추나를 넣고, 본인부담은 "나머지 30% + 추나 50%"로 계산한다고 OK차트가 씁니다 [S]. 추나를 넣은 총액이 구간 안에 들 때와 절사 단위(따로 버리는지 합친 뒤 한 번 버리는지)는 확인하지 못했습니다 [U]

### 첩약 건강보험 시범사업 (2단계) [P]

- 기간은 2024.4.29–2026.12.31이고, 한의원 본인부담은 **30%**입니다(보건복지부 보도자료 2024.4.29, 지침 제2장 Ⅰ.나)
- 첩약분(특정내역 `S027` 명세서)은 65세 정액, 6세 미만 경감, 산정특례, 차상위 경감을 모두 적용하지 않습니다(지침 Q&A). 같은 날 그 밖의 진료는 명세서를 나누고(`S028`) 현행 부담률을 따르며, 65세 이상이면 "투약처방 하지 않는 경우" 구간입니다
- 본인부담률구분코드 `U`는 100/100입니다. 질환별 연 20일 초과, 한의사 1인당 하루 8건·월 60건·연 600건 초과가 그렇습니다([pilot-herbal-diagnosis-limit](pilot-herbal-diagnosis-limit.md), [pilot-herbal-doctor-limit](pilot-herbal-doctor-limit.md))
- 건강보험(차상위 포함)만 대상이고 의료급여는 대상이 아닙니다
- 2027년 이후 연장이나 본사업 전환은 확인하지 못했습니다 [U]

### 차상위·산정특례 [P]

| 대상 | 한의원 외래 본인부담 |
|---|---|
| 차상위 1종 (`C`) | 0원 |
| 차상위 2종 (`E`·`F`) | 직접조제 1,500원, 그 밖 1,000원, 1세 미만 0원 |
| 차상위 2종 장애 | 750원 / 250원 [S] |
| 산정특례 희귀·중증난치 | 10% |
| 산정특례 중증(암·심장·뇌혈관 등) | 5% |
| 조산아·저체중아 | 5% |

원문 구조상 제3호(특례·차상위)가 제1호(65세 정액)보다 먼저 적용됩니다("제1호와 제2호에도 불구하고").

### 비급여와 100/100 [P]

별표 3의 판정 기준은 "요양급여비용 총액"이라 비급여는 들어가지 않습니다. 100/100 전액본인부담(첩약 `U` 등)은 명세서에서 "요양급여비용총액 1"이 아니라 "100분의100 본인부담금총액"으로 따로 적으므로 65세 구간 판정에서도 빠집니다. 이 결론은 명세서 구조에서 끌어낸 것입니다.

### 수납 계산에 영향이 없는 것

- 본인부담상한제: 공단이 사후에 환급합니다
- 연 365회 초과 외래 90%(건보)·30%(의료급여): 공단 통보 기반이라 의원이 판정하지 않습니다 [U]

## 확인하지 못한 항목

- 추나 80% 고시 원문과 추나 + 일반의 절사 단위·65세 구간 처리 (HIRA 청구방법 세부작성요령, 추나 Q&A)
- 의료급여 본인부담여부 코드(`M001`–`M018`, `B001`–`B014`, `U001`)의 공식 정의. 이 문서의 코드 의미는 OK차트와 현행 접수 화면에서 읽은 것입니다
- 산정특례 V코드 목록, 임신부 `F015`·조산아 `F016` 원문 (HIRA 특정기호 표)
- 의원급 차상위 임신부가 5%인지 정액 1,000원인지
- 첩약 시범사업 2027년 이후
- 건보 365회 기준을 300회로 낮추는 시행령 개정 (2026년 하반기 예정, 2026-11-07 현행 판에는 없음)
