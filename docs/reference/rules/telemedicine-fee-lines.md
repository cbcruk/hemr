# 비대면진료 시범사업 관리료 라인

## 요약

- 비대면 시범사업 진료(`비대면시범사업여부 = true`)면 진찰료 라인 하나마다 "비대면진료 시범사업 관리료" 라인을 하나씩 붙입니다. 카테고리는 `31001001`입니다.
- 코드는 진료 시각대로 정합니다. `91001` 주간, `91002` 야간, `91003` 심야, `91004` 공휴입니다. 시간대는 병원 설정과 무관하게 고정입니다.
- 금액은 수가 마스터가 아니라 클라이언트 상수로 계산합니다. 점수 28.79 × 연도별 점수당 단가(2025: 102.4, 2026: 104.3)를 10원 단위로 반올림합니다. 2026년은 3,000원, 2025년은 2,950원입니다.
- 비대면을 켜면 진찰료가 가산 없는 기본코드로 바뀝니다. 끄면 관리료 라인을 지우고 진찰료 가산을 다시 계산합니다. 진료 시각이나 진찰료 개수가 바뀌면 관리료 라인을 맞춥니다.

## 로직

### 시간대와 금액 (`Pd` → `Ed`)

1. `공휴일임 = 공휴일 맵에 yyyyMMdd가 있음 || 일요일`
2. `기준일시`가 정확히 12자리 숫자가 아니면 `Ed`가 예외를 던집니다.
3. `zd`
   - 공휴일임 → 공휴
   - 시각(시 + 분/60)이 7 미만 → 심야
   - 9 미만 → 야간
   - 18(토요일은 13) 미만 → 주간
   - 20 미만 → 야간
   - 그 밖 → 심야
4. 금액은 `round(28.79 × 단가 / 10) × 10`입니다. 단가는 진료 연도의 `Jsn` 값입니다. 표에 없는 연도는 2026 단가를 쓰고 `console.error`만 남깁니다.
5. 라인은 `처방명 "비대면진료 시범사업 관리료"`, `금액 = 단가 = 계산값`, `일투여량 = 투약일수 = 1`, `승인여부 false`, `급여항구분 "1"`입니다.

### 비대면 토글 (`Wh`)

1. 진찰료 = 코드가 `10`으로 시작하는 라인, 나머지 = 진찰료도 관리료(`xo`)도 아닌 라인입니다.
2. 진찰료가 없거나, `설정`이 없거나, 수가 마스터가 비면 `Eu`만 적용합니다. 진찰료는 원래 줄 그대로입니다.
3. 아니면 진찰료 중 `10100`으로 시작하는 게 있으면 초진, 없으면 재진입니다. 진찰료 규칙 `lee`에 `비대면진료임 = 비대면지정됨`을 넣어 코드를 다시 구합니다. 비대면이면 기본코드만, 대면이면 가산·토요 쌍이 나옵니다.
4. 마스터에서 찾은 라인으로 진찰료를 교체합니다. 첫 라인에는 야간 특정내역 `JS010`을 붙일 수 있습니다. 하나도 못 찾으면 원래 진찰료 줄을 유지합니다.
5. `Eu`: 관리료 라인을 모두 지웁니다. `비대면지정됨`이면 진찰료 개수만큼 `Ed` 라인을 **끝에** 붙입니다.

### 동기화 (`Uv`)

- 다른 `진료Id`로 바뀌면 보류 플래그를 지우고 아무것도 하지 않습니다.
- `활성`이 거짓이거나 공휴일 맵이 아직 없으면, 토글 변경과 시각·개수 변경을 보류 플래그로 기억했다가 다음 실행 때 반영합니다.
- `자보1일2차여부`면 아무것도 하지 않습니다. `기준일시`가 비면 보류합니다.
- 토글이 바뀌었으면(보류분 포함) `Wh`를 실행합니다.
- 그 밖에는 비대면일 때만 처리합니다.
  - 진찰료 개수가 바뀌어 관리료 라인이 진찰료보다 많으면 앞쪽부터 진찰료 수만큼만 남깁니다.
  - 기준일시가 바뀌었고 첫 관리료 라인이 `qh` 참이면, 모든 관리료 라인의 코드·금액·단가를 새 값으로 바꿉니다. `qh`는 시간대 코드가 다르거나 금액이 다르면 참입니다.

## 서버 이전 시 주의

- **금액이 하드코딩입니다.** 점수 28.79와 연도별 점수당 단가가 클라이언트 상수입니다. 2027년부터는 단가 표를 고치기 전까지 2026 단가로 청구됩니다(콘솔 오류만). 서버는 수가 마스터나 단가 테이블에서 가져와야 합니다.
- **시간대가 병원 설정과 다릅니다.** 관리료 시간대는 07·09·18(토 13)·20시 고정입니다. 대면 진찰료 야간 판정은 `주간진찰료산정기준` 설정을 씁니다. 같은 진료라도 기준이 달라질 수 있습니다.
- **진찰료 가산 제거.** 비대면이면 진찰료 규칙이 입력 코드를 그대로 돌려주므로 연령·야간·공휴·토요 가산이 모두 빠집니다. 의도된 청구 규칙인지 확인이 필요합니다.
- **조건 부족 시 진찰료 미정리.** 설정·마스터가 없거나 기본코드가 마스터에 없으면 가산 붙은 진찰료가 그대로 남은 채 관리료가 붙습니다.
- **관리료 개수.** 진찰료 줄마다 하나씩 붙입니다. 토요 쌍처럼 진찰료가 둘인 상태(비대면 전환 경로 외)에서는 관리료도 둘이 될 수 있습니다(`TreatmentPayment`의 `P`, 자동 삽입 경로).
- **`xo` 범위.** 정확히 `91001`~`91004`만 관리료로 봅니다. `91000…` 코드는 관리료로 보지 않습니다([coverage-category-band](coverage-category-band.md)에서도 둘을 다르게 다룹니다).
- **반응형 동기화.** 갱신은 화면 watcher가 합니다. 비활성·공휴일 로딩 중 변경은 보류했다가 반영하고, 진료를 바꾸면 보류분을 버립니다. 화면을 열지 않으면 갱신되지 않습니다. 서버는 진료 시각·비대면 여부·진찰료 변경 시 명시적으로 다시 계산해야 합니다.
- **날짜 형식 엄격성.** 12자리가 아니면 예외로 화면 동작이 멈춥니다. `Pd`는 같은 입력에 예외 없이 Invalid Date(공휴 아님)를 냅니다.
- **동일일자 대면/비대면 진찰료 중복**(`Uh`)은 [duplicate-consultation-fee](duplicate-consultation-fee.md)에서 다룹니다.
