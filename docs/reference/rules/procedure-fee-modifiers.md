# 시술·조제료 산정코드 (연령·침법 가산)

## 요약

- 시술(`40`으로 시작)과 투약·조제료(`30`으로 시작) 5자리 수가코드 뒤에 산정코드 3자리를 붙여 8자리 코드를 만듭니다. 세 자리가 모두 `0`이면 코드를 바꾸지 않습니다.
- 첫째 자리는 연령입니다.
  - 시술: 1세 미만 `3`, 신생아(침술 카테고리) `1`, 1~6세 미만 `6`
  - 투약·조제: 1세 미만 `1`, 1~6세 미만 `6`
- 셋째 자리는 경혈침술(`40011`, `40012`)의 침법입니다. 자락·도침·산침 `2`, 사암·오행·체질침 `4`, 화침·온침 `6`.
- 처방 목록을 넣으면 줄마다 바꾼 코드로 수가 마스터 행을 찾아 처방명·금액을 교체합니다. 마스터에 없으면 그 줄은 그대로 둡니다.

## 로직

### `JLt`

1. `수가코드`가 없거나, `산정코드재설정`이 아닌데 이미 8자리면 `undefined`(변경 없음)입니다.
2. 만 나이 `y`를 구합니다. 계산 방식은 진찰료와 같습니다([consultation-fee-code](consultation-fee-code.md)).
3. `연령에따른시술료가산적용여부 && y !== null`이면
   - 투약·조제(`30…`): `y < 1` → `1`, `1 ≤ y < 6` → `6`
   - 시술(`40…`)이고 변증기술료 `40400`이 아니면 `y < 1` → `3`, `1 ≤ y < 6` → `6`. 다만 `y < 1`이고 카테고리가 침술 `33001001`이고 생후 28일 이하(`sn.신생아임`)면 `1`입니다
   - 진찰료(`10…`)·검사(`20…`) 등은 바꾸지 않습니다
4. 코드가 `40011`(경혈) 또는 `40012`(경혈 이체)로 시작하면 셋째 자리를 정합니다. 자락도침산침술법 `2`, 사암오행체질침법 `4`, 화침온침 `6` 순으로 검사해 마지막 참이 이깁니다.
5. 둘째 자리는 `토요주간임` `3` → `야간임` `1` → `공휴일임` `5` 순으로 덮어씁니다. 코드 종류는 보지 않습니다. **현행 호출부는 이 세 플래그를 넘기지 않습니다.**
6. 세 자리가 `"000"`이면 `undefined`, 아니면 `앞 5자리 + 세 자리`를 돌려줍니다.

### `ZLt`

1. `설정`·`기준일시`·`환자` 중 하나라도 없으면 `null`(호출부는 원래 목록 유지)입니다.
2. `비대면진료임`이면 목록을 그대로 돌려줍니다.
3. 줄마다 `JLt`(침법·시간 플래그 없음)를 부릅니다. 결과가 없거나 마스터에 없으면 그 줄을 그대로 둡니다.
4. 마스터에 있으면 다음처럼 바꿉니다.
   - `수가코드`: 새 코드
   - `처방명`: `한글명_산정명칭 || 한글명`
   - `금액`: `Number(한방병의원단가)`
   - `단가`: `한방병의원단가 × 일투여량 × 투약일수`(반올림)

## 서버 이전 시 주의

- **나이 계산 버그 의심.** 진찰료와 같은 함수라 최근 약 한 달 안에 태어난 환자는 나이가 `null`이 되고 연령 가산이 모두 빠집니다. 신생아 `1`은 평년 2월 1일생이 3월 1일에 진료받는 식의 경계에서만 나옵니다. 그대로 옮길지 결정이 필요합니다.
- **시간대 가산은 사실상 쓰이지 않습니다.** `JLt`의 야간·공휴·토요 플래그를 넘기는 호출부가 없습니다. 그래서 시술 공휴 가산(`…050`)은 자동으로 붙지 않습니다. `_t`는 시술 야간·공휴를 해석할 줄 알지만 만드는 경로가 없습니다. 원래 의도를 확인해야 합니다.
- **플래그에 코드 종류 검사가 없습니다.** 조제료에도 `…010`을 만듭니다. 이 코드는 `_t` 해석에서 의미가 없습니다.
- **1세 미만 자리 값이 코드 종류마다 다릅니다.** 시술 `3`, 투약 `1`, 진찰료 `1`입니다. 진찰료용 헬퍼 `zk.만1세미만.적용`은 투약에 `3`을 쓰므로 일관되지 않습니다. 실제 투약 경로는 `JLt`를 씁니다.
- **마스터에 없으면 조용히 원래 코드로 둡니다.** 연령 가산 코드가 그 적용일자 마스터에 없으면 가산 없이 청구됩니다.
- **금액·단가 이름.** `금액`에 단가, `단가`에 총액이 들어갑니다. `l_`도 같습니다. 필드 의미를 확정한 뒤 옮겨야 합니다.
- **재계산 시점.** 처방 배열을 통째로 바꾸는 편집에만 돌고, `산정코드추가안함` 옵션이나 `vx` 모드에서는 건너뜁니다. 진료일·환자를 바꾼 뒤 기존 줄을 다시 계산하지 않습니다(8자리면 건너뜀). 서버는 명시적 재계산 시점이 필요합니다.
