# 진찰료 수가코드 판정 (초진/재진·가산)

## 요약

- 진료 1건에 넣을 진찰료 라인을 정합니다. 기본코드는 초진 `10100`, 재진 `10200`입니다. 최근 `초진진찰료산정기준일`일 안에 다른 진료가 있으면 재진입니다.
- 기본코드 뒤에 산정코드 3자리를 붙여 8자리 코드를 만듭니다. 첫째 자리는 연령(1세 미만 `1`, 1~6세 미만 `6`), 둘째 자리는 시간대(야간 `1`, 심야 `2`, 토요 `3`, 공휴 `5`, 대리수령 `9`), 셋째 자리는 차등수가 제외(`1`)입니다. 세 자리가 모두 `0`이면 5자리 기본코드만 씁니다.
- 토요 가산은 코드를 바꾸지 않습니다. 기본 진찰료 라인과 별도로 둘째 자리 `3` 코드 라인을 **하나 더** 추가합니다.
- 계산한 코드가 그 날짜의 수가 마스터(`수가코드목록`)에 없으면 진찰료 라인을 아예 만들지 않습니다.

## 로직

### 초진/재진 (`QLt`)

1. 현재 처방에 `10100`·`10200`·`91000`(비대면 시범사업)으로 시작하는 코드가 하나라도 있으면 아무것도 넣지 않습니다.
2. `p = 기준일시`, `m = p - 초진진찰료산정기준일(일)`. 둘 다 분 단위 시각입니다.
3. 최근 진료 중 `기준일시`가 있고, `진료Id`가 현재 진료와 다르고, `m < 기준일시 < p`(둘 다 엄격 부등호)인 것이 하나라도 있으면 재진, 없으면 초진입니다.
   - 정확히 N일 전 같은 분은 포함하지 않습니다(초진). 1분 늦으면 재진입니다.
   - 같은 시각의 다른 진료와 이후 시각의 진료는 세지 않습니다.
   - `초진진찰료산정기준일 = 0`이면 범위가 비어 늘 초진입니다.
4. `lee`로 코드 1~2개를 받아 각각 `l_`로 라인을 만듭니다. 카테고리는 `31001001`(한방진찰료)입니다. 첫 라인에 `aee`를 적용해, 야간 코드면 `줄단위특정내역`에 `{특정내역구분: "JS010", 특정코드내용: 기준일시}`를 붙입니다.
5. 초진이고 `초진환자처방시변증기술료적용여부`가 켜져 있으면 변증기술료 `40400`(카테고리 `33001099`)을 추가합니다. 조건은 현재 처방에 `40400`이 없고, 침술·구술·부항술·추나(`33001001`~`33001005`, 온냉경락 제외), 자보 시술·처치(`73001001`, `73002001`), 한방조제료(`34002001`) 카테고리 라인이 하나라도 있는 것입니다. 재진에는 붙이지 않습니다.

### 가산 (`lee`)

입력: `수가코드`(5자리), `기준일시`, 주민번호, `설정`, `holidays`, `비대면진료임`, `토요가산강제적용`, `대리수령자가처방전및약제수령함`.

1. `비대면진료임`이면 `[수가코드]`를 그대로 돌려줍니다.
2. 만 나이 `w`를 구합니다. 주민번호 앞 6자리와 뒷자리 첫 글자로 생년을 정합니다. 계산할 수 없으면 `null`입니다.
3. `연령에따른시술료가산적용여부`가 켜져 있고 `w`가 있으면
   - `w < 1` → 첫째 자리 `1`
   - `1 ≤ w < 6` → 첫째 자리 `6`
4. 플래그를 계산합니다.
   - `senior = w ≥ 65`
   - `holiday = holidays에 yyyyMMdd 키가 있음 || 일요일`
   - `S = 토요일공휴일시니어환자제외여부 && senior`
   - `C = (!S && !holiday && 토요일주간) || 토요가산강제적용`
   - `토요일주간`: 토요일이고 `min(09:00, 주간시작) ≤ 시각 ≤ 13:00`(양 끝 포함)
5. 야간: `야간진료시진찰료가산여부 && !C`이고 `(!시니어환자제외여부 || !senior)`이며 야간 시각이면 둘째 자리 `1`.
   - 평일 야간: `시각 < 주간시작` 또는 `시각 ≥ 주간종료`
   - 토요일 야간: `시각 < 주간시작` 또는 `시각 ≥ 13:00` (주간종료 설정은 무시)
6. 심야: `시각 ≥ 22:00`이고 `1 ≤ w < 6`이고 `!C`면 둘째 자리 `2`. 야간 설정과 무관하게 적용되고 야간 `1`을 덮어씁니다. 1세 미만과 성인은 해당하지 않습니다.
7. 공휴: `holiday && !C && !S`면 둘째 자리 `5`. 야간·심야를 덮어씁니다.
8. 대리수령: 플래그가 켜져 있으면 둘째 자리 `9`. 앞의 값을 모두 덮어씁니다.
9. `C`면 `[현재코드, 현재코드의 둘째 자리를 3으로 바꾼 코드]`를, 아니면 `[현재코드]`를 돌려줍니다.

둘째 자리는 하나뿐이라 마지막에 쓴 값이 이깁니다. 순서는 야간 → 심야 → 공휴 → 대리수령입니다.

### 코드 해석 (`_t.New`)

`앞 5자리 / 6번째 / 7번째 / 8번째`로 자릅니다. 둘째 자리 `1` 야간과 `5` 공휴는 진찰료(`10`)와 시술(`40`)에서만, `2` 심야·`3` 토요·`9` 대리수령은 진찰료에서만 의미가 있습니다.

## 서버 이전 시 주의

- **만 나이 계산 버그 의심.** `new Date(i, o, a)`에서 월을 -1 하지 않아 생일이 한 달 늦게 잡힙니다. 그래서 최근 한 달 안에 태어난 환자는 나이가 `null`이 되고 1세 미만 가산이 빠집니다(픽스처 `infant born 2026-02-05`). 생후 28일 이하에만 붙는 신생아 가산(`JLt` 첫째 자리 `1`)은 사실상 적용되지 않습니다. 생일 당일 판정 등 나머지 경계는 정상입니다. 서버가 그대로 옮길지는 결정이 필요합니다.
- **토요 가산은 두 라인입니다.** 기본 진찰료와 `…030` 라인이 함께 남습니다. 청구 형식이 이 표현에 의존하는지 확인해야 합니다.
- **마스터에 코드가 없으면 조용히 빠집니다.** 소아 야간 `10100610` 같은 조합이 해당 적용일자 마스터에 없으면 진찰료가 아예 들어가지 않고 오류도 나지 않습니다.
- **시각 기준.** 모든 판정은 클라이언트 로컬 시각(KST 전제)과 분 단위 `기준일시`로 합니다. 재진 창은 날짜가 아니라 시각으로 비교합니다. 서버는 Asia/Seoul로 고정해야 합니다.
- **서버가 이미 거른 데이터에 의존합니다.** 최근 진료 목록은 서버가 `days_ago`·`limit`·`type`으로 거른 결과입니다. `days_ago` 경계의 정확한 의미는 클라이언트에서 보이지 않습니다. 자보·산재는 조회 창이 다른데 판정에는 여전히 `초진진찰료산정기준일`을 씁니다.
- **공휴일 데이터.** 진료 연도 맵 하나만 씁니다. 조회 오류면 빈 맵이 되어 공휴일이 평일로 처리됩니다. 로딩 중이면 수동 버튼이 동작하지 않습니다.
- **`초진진찰료산정기준일` 기본값 0**이면 늘 초진입니다. 실제 설정인지 미설정 값인지 확인이 필요합니다.
- **경쟁 조건.** 자동 삽입은 화면 상태가 바뀔 때 돌고, 이미 진찰료가 있으면 건너뜁니다. 날짜·환자를 바꾼 뒤 기존 진찰료 코드를 다시 계산하지는 않습니다(수동 토글 필요).
- **관련 규칙.** 동일일자 진찰료 중복은 [duplicate-consultation-fee](duplicate-consultation-fee.md), 비대면 관리료 라인은 [telemedicine-fee-lines](telemedicine-fee-lines.md), 시술료 산정코드는 [procedure-fee-modifiers](procedure-fee-modifiers.md)에 있습니다.
